## Функция 1. Чтение базы данных из excel файла

### Текст задачи
Реализовать чтение данных из файла `LR5-var11.xlsx` (с тремя листами: «Картины», «Художники», «Стиль») с помощью сторонней библиотеки.

### Алгоритм решения
Для работы с Excel-файлами используется NuGet-пакет **ClosedXML**. 
В классе `HermitageRepository` реализован метод `Load()`. Он открывает файл по указанному пути и считывает данные с трех листов в соответствующие коллекции `List<>`: `Paintings`, `Artists`, `Styles`. 
Для надежности реализована защита от пустых строк, некорректных типов данных (например, если в колонке ID случайно введен текст) и обработка исключения `FileNotFoundException` на случай, если файл не найден по указанному пути.

## Функция 2. Просмотр базы данных

### Текст задачи
Вывести считанные данные в консоль в удобном для пользователя виде.

### Алгоритм решения
В классе `HermitageRepository` реализован метод `GetPaintingsView()`, который выполняет LINQ-запрос с `LEFT JOIN` (объединение таблиц «Картины», «Художники» и «Стиль»). 
Результат проецируется в специальный вспомогательный класс `PaintingView`. В консольном интерфейсе при выборе пункта 1 вызываются методы, которые выводят данные. Благодаря переопределенному методу `ToString()` в классах моделей, каждая запись отображается в структурированном виде. Если записей нет, выводится сообщение `(пусто)`.

## Функция 3. Удаление элементов (по ключу)

### Текст задачи
Реализовать удаление записи о картине по её уникальному идентификатору (ID).

### Алгоритм решения
В классе `HermitageRepository` реализован метод `DeletePainting(int id)`. С помощью LINQ-метода `FirstOrDefault` осуществляется поиск элемента в коллекции по ID. Если элемент найден, он удаляется из списка, и метод возвращает `true`. Если элемента с таким ID нет - возвращается `false`.
В интерфейсе консоли реализован пункт меню 2. Ввод пользователя проверяется через `int.TryParse` (защита от ввода букв), а результат удаления сообщается пользователю («Удалено» или «Картина не найдена»).

## Функция 4. Добавление элементов

### Текст задачи
Реализовать добавление новой записи о картине с автоматическим присвоением нового ID.

### Алгоритм решения
В классе `HermitageRepository` добавлены методы:
* `NextPaintingId()` - находит максимальный существующий ID и возвращает `Max + 1`.
* `AddPainting(Painting painting)` - добавляет новый объект в коллекцию. В методе предусмотрена проверка на дубликат ID (выбрасывается исключение `InvalidOperationException`, если ID уже существует).

В консольном меню (пункт 3) реализован пошаговый опрос пользователя для ввода названия, ID художника, части Эрмитажа, года и ID стиля. Если пользователь оставляет поле года пустым, оно корректно сохраняется как `null`. Название картины не может быть пустым.

## Функция 5. Реализация 4 запросов

### Текст задачи
Реализовать 4 LINQ-запроса:
1. 1 запрос с обращением к одной таблице (возвращает перечень).
2. 1 запрос с обращением к двум таблицам (возвращает одно значение).
3. 2 запроса с обращением к трем таблицам (один возвращает перечень, другой - одно значение).

### Алгоритм решения и формулировки запросов
Все запросы реализованы в виде методов класса `HermitageRepository` с использованием синтаксиса LINQ query expression.

**Запрос 1 (1 таблица, возвращает перечень):**
*Формулировка:* Получить перечень всех картин, созданных в XIX веке (год от 1800 до 1899). Сортировать по году.
*Метод:* `Query1_PaintingsOf19thCentury()`.

**Запрос 2 (2 таблицы, возвращает одно значение):**
*Формулировка:* Определить количество картин, созданных до 1600 года, у которых известен художник (связь таблиц «Картины» и «Художники»).
*Метод:* `Query2_OldPaintingsCountWithArtists()`.

**Запрос 3 (3 таблицы, возвращает перечень):**
*Формулировка:* Получить список картин с указанием ФИО художника и названия стиля для всех картин, находящихся в 1-й части Эрмитажа (связь таблиц «Картины», «Художники», «Стили»).
*Метод:* `Query3_Part1WithArtistAndStyle()`.

**Запрос 4 (3 таблицы, возвращает одно значение):**
*Формулировка:* Определить количество художников, у которых более 5 картин находится во 2-й части Эрмитажа. (Пример из задания).
*Метод:* `Query4_ArtistsWithMoreThan5InPart2()`. Реализован через группировку `group by` и условие `Count() > 5`.

## Функция 6. Сохранение изменений в excel файле

### Текст задачи
Сохранить все внесенные изменения (добавленные, удаленные записи) обратно в исходный Excel-файл.

### Алгоритм решения
В классе `HermitageRepository` реализован метод `Save()`. Он открывает существующий файл (или создает новый, если файл отсутствует) с помощью `ClosedXML`. 
Для каждого листа («Картины», «Художники», «Стиль») вызывается вспомогательный метод `SaveSheet()`, который:
1. Очищает текущий лист от старых данных (`ws.Clear()`).
2. Записывает заголовки таблицы.
3. Построчно выгружает данные из коллекций `List<>` в ячейки Excel с помощью `XLCellValue.FromObject()`.

В консольном меню реализован пункт 9, который вызывает этот метод. После нажатия пользователь видит сообщение об успешном сохранении. Если файл открыт в другой программе (например, в самом Excel), предусмотрен перехват ошибки `IOException` с выводом понятного сообщения о том, что файл занят.
